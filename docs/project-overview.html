Executive Summary

The Field Reporting System (FRS) replaces paper dailies and spreadsheet chasing. Field crews capture pay-item quantities on mobile; division managers approve or return reports; project admins track progress and export billing documentation.

Latest capabilities: Four smart bid form types, line type & side capture, manual LF entry, STA overlap validation, admin progress bars, Form E026 ledger with running to-date totals, and full approve / return audit trail.

Problem solved

Manual daily reports, lost tickets, delayed approvals, billing reconciliation gaps.

Primary users

Field leads, division managers, project admins, system administrators.

Outcome

Traceable quantities from field entry → approval → E026 ledger → billing export.

End-to-End Business Flow

1. Project setup

Create project → Assign team → Add tasks → Assign field leads → Set STA work limits

2. Field reporting

Select project → Enter quantities → Attach photos → Submit for approval

3. Manager approval

Review queue → Approve Approve with notes Return

4. Reports & billing

Progress bars → E026 ledger → Billing export

Report status lifecycle

Draft → Under review → Approved
Under review → Returned → Resubmitted

Roles & Workspaces

Project Admin

Create projects, assign tasks & field leads, view reports, E026 ledger, billing export.

Field Lead

Daily report entry on mobile, four form types, attachments, submit & resubmit returned reports.

Division Manager

Approve, approve with notes, or return reports with required comments.

System Admin

Users, permissions, bid master, clients, units, and full platform configuration.
